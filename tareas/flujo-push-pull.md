1. ¿Qué significa hacer `push`?
Push es para subir cambios al remoto
2. ¿Qué significa hacer `pull`?
Pull es para traer actualizaciones del remoto al local
3. ¿Cuál es la diferencia entre repositorio local y remoto?
el local esta en el pc y el remoto es el que se guarda en la nube y se puede compartir
4. ¿Por qué es importante hacer `pull` antes de empezar una tarea?
Porque nos permiter tener la ultima version del repositorio, Evitar desfaces.
5. ¿Por qué es importante hacer `push` después de hacer commits?
Porque me permite subir mis cambios realizados y que otros lo puedan ver
6. ¿Qué significa `origin`?
Es el nombre que le da por defecto git al repositorio remoto
7. ¿Qué significa `main`?
Es la rama de donde se descargan o se suben cambios en el repositorio remoto
8. ¿Qué comando usarías para subir una rama llamada `tarea/mi-practica`?
git push origin tarea/mi-practica
