# Curso Fullstack Básico - Material de Apoyo

Bienvenida al repositorio de material de apoyo del **Curso Fullstack Básico**.

Este repositorio será el espacio principal donde se organizarán los materiales, guías, ejercicios, tareas y recursos necesarios para avanzar durante el curso.

También será usado para practicar el flujo de trabajo con **Git** y **GitHub**, incluyendo ramas, commits, push, pull y Pull Requests.

---

## Propósito del repositorio

Este repositorio no será solamente un lugar para guardar archivos.

Será una guía de aprendizaje donde se irá construyendo paso a paso el conocimiento necesario para desarrollar una aplicación web completa.

Aquí se publicarán:

* Material de clase.
* Guías paso a paso.
* Ejercicios prácticos.
* Tareas.
* Recursos de apoyo.
* Comandos útiles.
* Ejemplos de código.
* Indicaciones para entregas mediante Pull Request.

La idea es que cada avance quede organizado y pueda ser consultado durante todo el curso.

---

## Objetivo del curso

El objetivo del curso es aprender los fundamentos del desarrollo web fullstack mediante la construcción progresiva de una aplicación funcional.

Durante el curso se trabajará el flujo completo de una aplicación web:

```txt
Frontend → API REST → Backend → Datos
```

Al finalizar, se espera que la estudiante pueda comprender cómo se conectan las diferentes partes de una aplicación web y cómo se trabaja un proyecto usando herramientas reales de desarrollo.

---

## Proyecto guía

Durante el curso se construirá un **sistema básico de reservas**.

Este proyecto permitirá practicar conceptos relacionados con frontend, backend, API REST, datos y programación orientada a objetos.

El sistema podrá manejar información como:

* Clientes.
* Servicios.
* Reservas.
* Estados de reserva.

El proyecto se construirá por etapas, acompañando los temas vistos en clase.

---

## Temas principales del curso

Durante el curso se trabajarán los siguientes temas:

1. Introducción al desarrollo fullstack.
2. Uso básico de Git.
3. Manejo de GitHub.
4. Creación de ramas.
5. Commits claros.
6. Push y pull.
7. Pull Requests.
8. Fundamentos de backend.
9. Creación de una API REST.
10. Fundamentos de frontend.
11. Consumo de API desde una página web.
12. Programación orientada a objetos.
13. Persistencia básica de datos.
14. Organización de un proyecto.
15. Presentación del proyecto final.

> **Estado actual:** el módulo de **Git y GitHub** (temas 2 a 7) ya está disponible en `recursos/git-github/`. El resto de los temas se irá publicando a medida que avance el curso.

## Forma de trabajo

Durante el curso practicaremos un flujo de trabajo similar al usado en proyectos reales.

Cada tarea o cambio importante deberá realizarse en una rama diferente.

El flujo general será:

1. Actualizar la rama principal.
2. Crear una rama para la tarea.
3. Realizar los cambios.
4. Guardar los cambios con commits.
5. Subir la rama a GitHub.
6. Crear un Pull Request.
7. Recibir revisión.
8. Aplicar correcciones si es necesario.
9. Finalizar la entrega.
