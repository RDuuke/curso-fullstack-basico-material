¿Qué es una rama?
Es una propiedad que nos ayuda a crear un nuevo flujo sin afectar el flujo principal
¿Para qué sirve una rama?
Para trabajar en un proyecto sin el riesgo de afectar el proyecto principal
¿Por qué no deberíamos trabajar directamente sobre main?
Para no dañar el flujo principal
¿Qué es un commit?
Son puntos de guardado de un proyecto
¿Qué características debe tener un buen commit?
El mensaje debe tener una acción y una breve descripción

¿Cuál es el flujo recomendado para iniciar una tarea?
git checkout main
git pull origin main
git checkout -b "name new branch"
¿Cuál es el flujo recomendado para guardar y subir cambios?
git status
git add .
git commit -m "mensaje"
git push origin tarea/nombre-de-la-rama
